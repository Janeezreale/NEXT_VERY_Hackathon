# B02·B03 소비자 화면 인수인계

모든 소비자 화면이 실제 데이터를 씁니다. 파일 이름의 `preview`는 초기 구조에서 남은 이름입니다.

| 화면 | 데이터 |
| --- | --- |
| `/shop` 상품 목록 | 실제 상품. 서버 계산 가격, 지역 필수, 최대 50개 |
| `/shop` 매장 지도 | 실제 매장 |
| `/shop/products/[id]` | 실제 상품과 매장. 품절·판매 종료 표시 |
| `/shop/products/[id]/reserve` | 실제 예약 요청. 방문 시각은 30분 간격, 최대 6개 |
| `/shop/reservations` | 로그인 사용자의 실제 예약. 예약 확정 상태에서 취소 가능 |

## 규칙

- 가격·할인율·총액은 서버 값을 표시하고 화면에서 계산하지 않습니다. 예약 전 예상 총액만 현재가로 표시합니다.
- API 응답은 `product-view.ts`, `reservation-view.ts`에서 화면 값으로 바꿉니다. 시각은 한국 시간입니다.
- 예약 요청 키는 결과를 모르는 재시도에서 유지하고, 선택을 수정하거나 요청이 확실히 실패하면 새로 만듭니다.
