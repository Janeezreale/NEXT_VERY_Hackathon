# 판매 리포트 UI 데모 · C03 일부

사용자가 이번 작업에서 명시적으로 요청한 리포트 UI입니다. 기존 C 담당 공통 파일은 수정하지 않습니다.
실제 리포트 API·DB·집계 계약은 연결하지 않으며 C03 전체 완료를 의미하지 않습니다.

- 고정된 당일(2026.10.31) / 7일(2026.10.25–31) 예시 기간을 선택합니다. 실제 오늘·실시간 기록이 아닙니다.
- 등록·예약 요청은 기간 내 발생, 판매 완료·매출은 기간 내 완료, 현재 승인은 기준 시점 상태라는 **데모 정의**입니다. 총괄의 D07 확정 전 집계 정책으로 사용하지 않습니다.
- Recharts 막대 차트와 같은 데이터를 일별 표로 제공합니다. 주간 완료 예시 22건·매출 예시 120,000원, 당일 3건·15,000원입니다.
- 매출은 순이익·정산액이 아닙니다. 수수료·비용·확정 폐기량을 추정하지 않습니다.
- 판매량·잔여 재고는 상품 단위로 표시하고 합산하지 않습니다. 잔여 재고는 기간과 무관한 상품 화면의 고정 시안입니다.
- 예약 화면의 데모 상태 변경과 리포트는 동기화하지 않습니다. 실제 완료·판매 기록을 생성하지 않습니다.
- 로딩·데이터 없음·오류는 예시 지표를 노출하지 않습니다. 재시도는 데모 화면 전환일 뿐 API 성공으로 위장하지 않습니다.

## 미리보기

```sh
node 'src/app/(seller)/seller/reports/preview.mjs'
```

http://127.0.0.1:3102/seller/reports 에 접속합니다. 같은 서버에서 나머지 판매자 화면도 이동할 수 있습니다.
예약 관리의 격리 미리보기 스크립트를 재사용합니다. Ctrl+C로 종료하고 소스 변경 후 재시작합니다.

```sh
node 'src/app/(seller)/seller/reports/preview.mjs' --build
```

320 / 390 / 768 / 1024px·200% 확대·키보드로 기간/상태 선택을 확인합니다.
차트는 장식적 시각화로 처리하고 같은 데이터의 캡션·열 제목·행 제목이 있는 표를 접근 가능한 대안으로 제공합니다.
Pretendard 자산·공통 디자인 시스템은 추가하지 않았으며 기존 시스템 폰트 폴백을 사용합니다.

## 검증 결과

- 전체 테스트 28개 통과. 리포트 6개는 기간별 합계·표, 상품 단위, 상태 화면에서 예시 매출 미노출을 확인합니다.
- lint 오류 0, 기존 설정 경고 1건. 격리 빌드의 컴파일·TypeScript·정적 페이지 생성 통과.
- HTTP 200과 주간 120,000원·데모 안내·판매 표 렌더링 확인.
- 전체 타입 검사는 기존 customer 빈 페이지, 전체 앱 빌드는 루트 레이아웃 부재로 실패합니다. 해당 파일들은 변경하지 않았습니다.
- 브라우저에서의 차트 실제 크기·툴팁·모바일 레이아웃·키보드 동작은 미검증입니다. 실제 집계·API·DB 검증도 수행하지 않았습니다.
