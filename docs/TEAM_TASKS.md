## 충돌 줄이기

- A는 `seller/report/`를 수정하지 않습니다. C는 그 외 판매자 화면을 수정하지 않습니다.
- 공통 컴포넌트가 필요하면 C에게 요구사항을 작업 카드로 전달합니다. 각자 복사본을 만들지 않습니다.
- 공유 타입·API 호출 방식·패키지 추가는 총괄이 통합합니다.
- API 미완료 상태에서 화면 명세와 승인된 타입 기반 UI 작업은 가능하지만, 가짜 실데이터를 넣거나 연동 완료로 표시하지 않습니다.
- 작업 완료는 검증 결과와 PR 링크가 있을 때 표시합니다. 현재 문서 틀과 개발 패키지·기본 설정을 준비했으며, 기능 구현 완료 항목은 없습니다.
