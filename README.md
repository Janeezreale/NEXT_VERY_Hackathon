# 라스트픽(LastPick)

판매자가 남은 상품을 사진으로 등록하고, 소비자가 지역별 할인 상품을 찾아 방문 수령을 예약하는 서비스입니다.

환경 준비와 명령은 [개발 환경 안내](docs/SETUP.md), 환경 변수 이름은 [.env.example](.env.example)을 참고합니다.
