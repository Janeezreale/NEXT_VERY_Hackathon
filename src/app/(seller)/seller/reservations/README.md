# 판매자 예약 관리 UI 데모 · A03 일부

사용자 요청으로 예약 목록·필터·상세·처리 미리보기를 구현합니다. 실제 연동 완료나 A03 전체 완료는 아닙니다.
상태는 초안의 5개 상태를 UI 표시 문구로 표현합니다. 공유 API 타입·DB·재고 정책은 만들지 않습니다.

- 승인 대기: 승인·거절 미리보기, 예약 승인: 판매 완료 미리보기.
- 확인 모달의 `데모 화면에서 … 표시`는 현재 화면의 상태값만 변경합니다.
- 서버 저장·재고 확보/차감/반환·결제·판매 기록 생성은 없습니다. 예약 당시 금액 예시는 그대로 유지합니다.
- 취소·Escape는 표시 변경을 적용하지 않습니다. 새로고침하면 모든 변경이 초기화됩니다.
- 다른 화면의 예약 요약·판매 리포트는 독립된 고정 시안이며 처리 미리보기와 동기화하지 않습니다.
- 고객 개인정보·미제공 거절 사유는 만들지 않습니다. 판매자의 예약 취소·자동 만료 등 미정 기능도 추가하지 않습니다.
- 상품·가게 화면과 같은 Fresh & Clean 팔레트, 44px 이상 조작 영역, 모바일 우선 카드와 CSS Module을 사용합니다.

## 미리보기

프로젝트 루트에서 설치된 의존성과 Node.js 24 / npm 11을 사용합니다.

```sh
node 'src/app/(seller)/seller/reservations/preview.mjs'
```

- 예약: http://127.0.0.1:3102/seller/reservations
- 리포트: http://127.0.0.1:3102/seller/reports
- 같은 서버에서 `/seller/dashboard`, `/seller/products`도 확인할 수 있습니다.

원본 파일 대신 OS 임시 폴더에 네 화면과 루트 레이아웃을 생성합니다. Ctrl+C로 종료하며 소스 변경 후 재시작해야 합니다.

```sh
node 'src/app/(seller)/seller/reservations/preview.mjs' --build
```

320 / 390 / 768 / 1024px, 키보드·Escape·포커스 복귀, 긴 상품명, 200% 확대를 수동 확인합니다.
5개 필터와 데모 상태 반영 후 목록·요약 갱신, 취소 시 상태 유지, 로딩·빈 목록·오류·필터 결과 없음 상태를 점검합니다.

## 검증 결과

- `npm run test:run`: 전체 28개 통과, 이 화면의 상태·필터·처리 버튼·상태 화면 테스트 9개 포함.
- `npm run lint`: 오류 0, 기존 `postcss.config.mjs` 경고 1건.
- 격리 `preview.mjs --build`: 판매자 네 화면 컴파일·TypeScript·정적 페이지 생성 통과.
- 예약·리포트 페이지 HTTP 200 및 주요 데모 내용 렌더링 확인.
- 전체 `npm run typecheck`: 기존 빈 customer 페이지 관련 TS2306 / TS2344 오류. 전체 `npm run build`: 공통 루트 레이아웃 부재로 실패.
- 실제 브라우저 클릭·반응형·포커스·스크린리더 검증은 미실행입니다. API·DB 연동 테스트도 범위에 포함되지 않습니다.
