# B02·B03 소비자 UI 미리보기

## 개발 전용

`npm.cmd run dev -- --port 3100` 실행 후 다음 경로를 확인합니다.

- `/shop`: 지역·업종·품목 필터와 상품 목록. 시연 도구에서 로딩·빈 결과·오류 선택.
- `/shop/products/preview-1`: 상세와 참고 사진·픽업 정보. 품절·판매 종료 시나리오 선택.
- `/shop/products/preview-1/reserve`: 수량·시간 선택 → 내용 확인 → 요청 화면 시연.
- `/shop/reservations`: 5개 상태의 고정 Mock 목록과 상태 필터·빈 목록.

## 범위

`preview-data.ts`는 개발 전용 UI 데이터이며 API 타입이나 실제 재고가 아닙니다.
페이지는 NODE_ENV가 development일 때만 시연을 표시합니다.
사진은 외부 Unsplash 참고 이미지이며 실패 시 이미지 없음으로 표시합니다.
서버 현재가와 예약 당시 확정가를 별도 예시로 구분합니다.
선택 수량의 예상 합계는 표시용 산술이며 가격 정책 엔진이 아닙니다.
선택·확인 단계는 메모리에만 있으며 예약을 생성하거나 내역에 추가하지 않습니다.

## 의존성 / 남은 작업

- 문서의 `(buyer)` 대신 기존 `src/app/(customer)/shop` 구조를 유지합니다.
- 실제 데이터·공유 타입·API·인증·가격 재확인·재고 확보·중복 방지는 총괄 영역입니다.
- D02 시간대·픽업 범위, D03 취소, D04 가격 변경, D06 재시도 정책은 미정입니다.
- C의 공통 컴포넌트·Pretendard 로딩·공통 테마 연결은 추후 합의가 필요합니다.
- UI 시연만 구현했으므로 B02・B03의 실제 연동 완료를 뜻하지 않습니다.
- 브라우저 도구 연결 불가로 시각 QA와 실제 클릭·키보드·모바일 검증은 남아 있습니다.

## 검증

TypeScript 검사·프로덕션 빌드 통과. 개발 서버에서 네 경로 HTTP 200 확인.
테스트 파일이 없어 test:run은 실패하며 테스트 통과로 간주하지 않습니다.
