## 3. 남은 검증

- 소비자 계정: `/api/me`, `/seller/*` 차단, 매장·상품 등록 차단.
- 다른 판매자 계정: 타 매장 수정·조회 차단.
- 브라우저: `/store`, `/seller/publish`의 입력, 시간 변환, 모바일 화면.
- 상품 2개 이상에서 `GET /api/seller/products` 다음 페이지.
- Vercel 배포 연결과 환경 변수.

## 4. 정리할 것

- 검증용 상품 `[검증] 삭제 예정 상품`(`7a0a726e-0fee-4ee8-a8b6-5a25bfc79b4f`)을 SQL Editor에서 삭제합니다.
- 공개 배포의 소비자 데모 데이터는 4번 작업에서 제거합니다.
- 소비자 데모의 꽃 상품·품목은 D10 확정 후 정리합니다.
- 직접 입력한 지역은 표기가 다르면 다른 지역으로 나뉩니다. 시연 매장은 주소 검색으로 등록합니다.
- `PATCH /api/seller/store`의 빈 요청은 전용 문구 대신 일반 안내를 반환합니다.
- 운영 전 이메일 인증을 다시 켜고 외부 SMTP와 Redirect URLs를 설정합니다.
- 브랜치 보호를 확인합니다(D09).
- Vercel에 네이버 지도 환경 변수를 추가하고 배포 도메인을 Web 서비스 URL에 등록합니다.
- 기존 `테스트 마켓`은 주소를 다시 검색해 저장해야 지도에 나옵니다.
